# 中高数学マップ

中学1年から数学III・Cまでを、夜空の星図としてたどる学習ページです。

- **星域** = 科目と学年（中学1〜3年、数学I・A・II・B・III・C）
- **星座** = 教科書の章
- **星** = 章の中の項。選ぶと、ねらい・図で見るしくみ・要点・例題・練習問題を1画面ずつ進めます
- **「なぜ」の星** = 公式や定理を自分で導く単元（ひし形・金色）

公開先: https://nightshrine.github.io/math-map/

## いまの範囲

- 星座は 37 個。星は 48 個。
- 数学II「微分法と積分法」は、教科書の節と項に合わせて 11 個の星に分けてあります（うち「なぜ」の星が 3 個）。章立ては数研出版の教科書に合わせています。
- それ以外の 36 章は、章全体を 1 つの星にまとめています（要点・例題・練習問題）。順に項ごとの星へ分けていく予定です。

## 構成

ビルドは不要です。`site/` の中身がそのまま公開されます。

| ファイル | 内容 |
|---|---|
| `site/index.html` | 画面の骨組みとスタイル |
| `site/core.js` | 星図（配置、移動と拡大、進み具合の保存） |
| `site/stage.js` | 星座の画面と、星のステージ（1画面ずつ進む） |
| `site/figs.js` | 動かせる図 |
| `site/stars-*.js` | 項ごとの星の中身（いまは「微分法と積分法」の章） |
| `site/data-*.js` | 章ごとの要点・例題・つながり |
| `site/problems-*.js` | 章ごとの練習問題（基本・応用・複合・発展） |

数式は MathJax、フォントは Google Fonts を外部から読み込みます。進み具合はブラウザの中だけに保存されます。

## 手元で見る

```sh
cd site && python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## 中身を足す

- **章を項ごとの星に分ける**: `site/stars-*.js` に `STARS.push({...})` で星を足します。`ch` に章の id、`sec` に節の名前、`kind` に `main`（本編）か `why`（なぜ）、`pre` に前提の星や章の id を書きます。星を持つ章では、今までの章の内容が自動で最後の「章のまとめ」になります。
- **画面の種類**（`screens` の `t`）: `intro`（ねらい）、`text`（説明）、`fig`（図）、`points`（要点）、`ex`（例題）、`quiz`（練習問題）、`ask`（選んで確かめる）。
- **図**: `site/figs.js` に `FIGS.名前` を足し、画面の `fig` で名前を指定します。
- **章や練習問題**: `site/data-*.js` と `site/problems-*.js` に足します。

数式（TeX）は必ず `tx()` を通して表示します。`<` を含む不等式が HTML のタグとして解釈されて切れるのを防ぐためです。

## デプロイ

`main` に入ると、GitHub Actions（`.github/workflows/deploy.yml`）が `site/` を GitHub Pages に公開します。
