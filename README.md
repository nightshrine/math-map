# 中高数学マップ

中学1年から数学III・Cまでを、夜空の星図としてたどる学習ページです。

- **星域** = 科目と学年（中学1〜3年、数学I・A・II・B・III・C）
- **星座** = 教科書の章（37 個）
- **星** = 章の中の項。選ぶと、ねらい・図で見るしくみ・要点・例題・練習問題を、縦にスクロールして読み進めます
- **「なぜ」の星** = 公式や定理を自分で導く単元（ひし形・金色）

公開先: https://nightshrine.github.io/math-map/

## 内容

- 37 の星座すべてを、教科書の項に合わせて星に分けてあります（星はおよそ 350 個、うち「なぜ」の星がおよそ 60 個）。
- 星には動かせる図が入っています。図形の証明は、根拠になる辺や角が手順ごとに強調される図で見せます。
- 練習問題は、基本・応用・複合（ほかの単元と組み合わせる）・発展の4段階です。解き方は1手ずつ表示できます。
- 各星座の最後の「章のまとめ」には、章全体の要点・例題・練習問題があります。
- 分からなくなったら、ステージの「前提」から前の単元へ移り、「続きに戻る」で元の位置に戻れます。
- 学習済みにした星（灯した星）と練習問題の「できた」は、ブラウザの中だけに保存されます。

章立ては、中学が啓林館「未来へひろがる数学」、高校が数研出版の教科書に合わせています（出版社の学習項目一覧・シラバスと高校の年間授業計画で確認。教科書の本文は参照していません）。

## 構成

ビルドは不要です。`site/` の中身がそのまま公開されます。

| ファイル | 内容 |
|---|---|
| `site/index.html` | 画面の骨組みとスタイル |
| `site/core.js` | 星図（配置、移動と拡大、進み具合の保存） |
| `site/stage.js` | 星座の画面と、星のステージ |
| `site/figs.js` | 図の共通部品（`plot` / `draw` / `FIG.mk`）と共通の図 |
| `site/stars-<章>.js` | 章ごとの星の中身 |
| `site/figs-<章>.js` | 章ごとの図 |
| `site/data-*.js` | 章の一覧・つながり・章のまとめの要点と例題 |
| `site/problems-*.js` | 章のまとめの練習問題 |
| `AUTHORING.md` | 星と図の書き方（執筆ガイド） |
| `tools/check.js` | 星と図のデータ検査 |
| `tools/sync-scripts.js` | `site/index.html` の script の並びを、ファイルから作り直す |

数式は MathJax、フォントは Google Fonts を外部から読み込みます。

## 手元で見る

```sh
cd site && python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## 中身を直す・足す

書き方は `AUTHORING.md` にあります。直したら、リポジトリの直下で次を実行します。

```sh
node tools/sync-scripts.js   # 章のファイルを足したときだけ
node tools/check.js          # エラーが 0 になるまで直す
```

検査は、構造・参照先・数式の括弧の対応・図の描画エラーを調べます。数学の正しさは調べません。

数式（TeX）は必ず `tx()` を通して表示します。`<` を含む不等式が HTML のタグとして解釈されて切れるのを防ぐためです。

## デプロイ

`main` に入ると、GitHub Actions（`.github/workflows/deploy.yml`）が `site/` を GitHub Pages に公開します。
